About this project

NASA's APIs are generous — real mission data, free — but they are honest about being a shared resource: the demo key allows 30 requests an hour across everyone on Earth using it. I learned that the hard way, mid-build, when the dashboard started returning 429s because strangers somewhere were also testing. So this project is built around quota literacy: the remaining budget is shown in the UI, failures degrade to a cached picture instead of a dead page, and your own free key (a one-minute signup) lifts the ceiling to 1,000 an hour. The asteroid table is the part I keep coming back to — some of these rocks pass closer than the Moon, and almost nobody notices.

Part of a series of small, dependency-free apps I built against free public APIs to practise working within real rate limits and payload shapes.
